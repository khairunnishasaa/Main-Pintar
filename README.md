## 🇮🇩 Bahasa Indonesia

### Apa ini?
Game belajar tanpa iklan dan tanpa akun untuk anak pra-TK. Anak memilih usia, teman bermain (9 tokoh hewan lucu), jenis permainan, dan level. Setiap level berisi 15 soal dengan kesulitan bertingkat.

### Isi permainan (11 jenis)
Berhitung, Pola Gambar, Pola Bayangan, Hubungkan Warna, Puzzle, Huruf Alfabet, Angka, Kenali Benda, Cocokkan Benda, Bentuk dan Ukuran, Ikatan Bilangan. Tiap jenis punya 10 level untuk usia 2, 3, 4, dan 5 tahun.

### Keputusan desain
- **Pendekatan CPA** (konkret, gambar, abstrak), terinspirasi Singapore Math. Di Berhitung dan Ikatan Bilangan, anak mulai dari menyentuh benda, lalu gambar, lalu angka.
- **Tanpa perlu membaca.** Anak 2–5 tahun belum bisa membaca, jadi soal memakai gambar, simbol, demo tangan 👆, dan tombol Bantuan 💡.
- **Tanpa hukuman.** Tidak ada timer soal. Jawaban salah diberi kesempatan mencoba lagi, dan semua anak mendapat piala 🏆 berapa pun skornya.
- **Berpikir berurutan.** Puzzle seret, menyusun pola, urutan kejadian, dan coding panah untuk usia 4–5 tahun.
- **Aman untuk anak dan nyaman untuk orang tua.** Pengingat istirahat (15/30/45/60 menit) dan pengaturan dikunci dengan soal tambah dua digit. Skor hanya tersimpan di perangkat.
- **Dua bahasa** (Indonesia dan English) dan **bisa dimainkan tanpa internet** setelah dibuka satu kali.

## 🇬🇧 English

### What is this?
An ad-free, account-free learning game for preschoolers. Children pick an age, a play buddy (9 cute animal characters), a game type, and a level. Every level has 15 questions that get gradually harder.

### What is inside (11 game types)
Counting, Picture Patterns, Shadow Match, Colors, Puzzle, Alphabet, Numbers, Know Objects, Match Objects, Shapes and Sizes, Number Bonds. Each type has 10 levels for ages 2, 3, 4, and 5.

### Design decisions
- **CPA approach** (concrete, pictorial, abstract), inspired by Singapore Math. In Counting and Number Bonds, children start with hands-on objects, then pictures, then numbers.
- **No reading needed.** Children aged 2–5 cannot read yet, so questions use pictures, symbols, a pointing-hand demo 👆, and a Help button 💡.
- **No punishment.** No question timers. Wrong answers get another try, and every child earns a trophy 🏆 whatever the score.
- **Sequential thinking.** Drag-and-drop puzzles, pattern building, story order, and arrow coding for ages 4–5.
- **Child-safe and parent-friendly.** A break reminder (15/30/45/60 minutes) and the settings are locked behind a two-digit addition question. Scores stay on the device.
- **Two languages** (Indonesian and English) and **works offline** after the first visit.

### Deploy on GitHub Pages
1. Create a public repository and upload all files in this folder.
2. Go to **Settings → Pages**, choose branch `main` and folder `/ (root)`, then **Save**.
3. Open the link. On a phone, choose **Add to Home screen** to use it like an app.
